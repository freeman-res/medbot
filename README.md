# Медбот

**Telegram-помощник клиники: от первого сообщения до контрольного осмотра.**

> Для пациента — понятный следующий шаг. Для клиники — единый порядок работы с пациентами и операциями.

У пациента перед операцией много вопросов: когда приехать, что взять с собой и к кому обратиться после выписки. «Медбот» строится вокруг одного диалога в Telegram, где организационные вопросы не теряются между звонками и переписками. Медицинские решения остаются за лечащим врачом.

## Путь пациента

| Этап | Что важно пациенту | Что делает клиника |
| --- | --- | --- |
| **До операции** | Знать дату, время прибытия и как подготовиться. | Назначает операцию и определяет инструкции по подготовке. |
| **После операции** | Иметь под рукой рекомендации по восстановлению и понимать, куда обращаться с вопросами. | Определяет рекомендации для конкретного вмешательства. |
| **Контрольный осмотр** | Знать, когда прийти на осмотр, и иметь возможность сообщить о самочувствии. | Организует осмотр и получает обратную связь от пациента. |

## Как устроен бот

- **Пациент** начинает с команды `/start` и регистрируется прямо в Telegram.
- **Сотрудник клиники** открывает меню `/admin`, добавляет пациента или назначает операцию: выбирает категорию и вид вмешательства, указывает дату и время прибытия.
- **PostgreSQL** хранит записи о пациентах, каталог вмешательств и назначенные операции. При запуске бот создаёт нужные таблицы и заполняет справочник.

**Стек:** Python · aiogram · PostgreSQL · asyncpg.

## Локальный запуск

Понадобятся Python, работающий PostgreSQL и токен Telegram-бота от BotFather. Создай пустую базу `clinic_bot` и выполни в PowerShell из корня проекта:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
Copy-Item .env.example .env
```

Заполни `.env`:

| Переменная | Что указать |
| --- | --- |
| `BOT_TOKEN` | Токен Telegram-бота. |
| `ADMIN_IDS` | Числовые Telegram ID администраторов через запятую. |
| `DATABASE_URL` | Строку подключения к PostgreSQL в формате `postgresql://user:password@localhost:5432/clinic_bot`. |

```powershell
.\.venv\Scripts\python.exe main.py
```

Для локальной проверки используй вымышленные данные. Не добавляй в Git токены, пароли и выгрузки базы.
